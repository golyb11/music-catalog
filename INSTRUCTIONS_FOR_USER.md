# Руководство по запуску и проверке проекта

Данный файл содержит подробную инструкцию по запуску веб-приложения «Каталог музыкальных альбомов» и пошаговый сценарий для проверки всех требований технического задания.

---

## 1. Варианты запуска

### Вариант А: Запуск через Docker (Рекомендуемый)

Для запуска одной командой требуется установленный и запущенный Docker Desktop.

1. **Скопируйте файл переменных окружения:**
   В терминале (cmd / powershell / bash) в папке проекта:
   ```bash
   cp .env.example .env
   ```
   *(В Windows PowerShell: `Copy-Item .env.example .env` или просто скопируйте файл вручную).*

2. **Запустите сборку и контейнеры:**
   ```bash
   docker compose up --build
   ```

3. **Что произойдет автоматически:**
   - Поднимется контейнер базы данных `PostgreSQL 16` с healthcheck.
   - Соберется production-образ приложения Next.js.
   - Применятся миграции Prisma (`prisma migrate deploy`).
   - Автоматически загрузятся демонстрационные данные (`seed.ts`): популярные исполнители, альбомы и треки, в том числе песни, входящие сразу в несколько альбомов с разными номерами.
   - Сервер запустится на `http://localhost:3000`.

4. **Остановка контейнеров:**
   ```bash
   docker compose down
   ```
   *(Если хотите сбросить базу данных с нуля: `docker compose down -v`)*.

---

### Вариант Б: Запуск локально (без Docker)

Требуется Node.js 20+ и локально запущенный PostgreSQL.

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Создайте `.env` и настройте подключение:**
   Скопируйте `.env.example` в `.env` и укажите ваш `DATABASE_URL`, например:
   ```env
   DATABASE_URL="postgresql://postgres:postgres@localhost:5432/music_catalog?schema=public"
   ```

3. **Сгенерируйте клиент Prisma и примените миграции:**
   ```bash
   npx prisma generate
   npx prisma migrate dev
   ```

4. **(Опционально) Заполните базу демо-данными:**
   ```bash
   npm run db:seed
   ```

5. **Запустите dev-сервер:**
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:3000`.

## 2. Пошаговый сценарий проверки функционала (Чек-лист ТЗ)

Откройте браузер по адресу [http://localhost:3000](http://localhost:3000).

### Шаг 1. Главная страница (Dashboard)
- Проверьте отображение карточек статистики: общее количество исполнителей, альбомов и песен.
- Проверьте блок «Недавно добавленные альбомы» и быстрый переход в разделы.

### Шаг 2. Исполнители (`/artists`)
- **Просмотр списка:** отображаются карточки исполнителей с аватарами (инициалы), именем и счетчиком альбомов.
- **Поиск:** введите в поле поиска имя артиста (например, *Pink Floyd* или *Queen*) — список мгновенно фильтруется.
- **Создание:** нажмите кнопку «Добавить исполнителя», введите имя и сохраните. Проверьте появление toast-уведомления.
- **Редактирование:** нажмите кнопку редактирования у исполнителя, измените имя.
- **Страница исполнителя (`/artists/[id]`):** перейдите в карточку — там отображаются все альбомы данного артиста.
- **Удаление:** попробуйте удалить исполнителя. Если у него есть альбомы, система предупредит об этом.

### Шаг 3. Альбомы (`/albums`)
- **Фильтрация и сортировка:**
  - Отфильтруйте по исполнителю через выпадающий список.
  - Отфильтруйте по диапазону года выпуска.
  - Проверьте сортировку: по названию, году выпуска, дате добавления.
- **Создание альбома:** нажмите «Создать альбом», выберите исполнителя, укажите название и год (например, 2024).
- **Детальная страница альбома (`/albums/[id]`):**
  - Отображается сгенерированная стильная обложка с градиентом, название, автор, год.
  - Отображается список треков, отсортированный по номерам (1, 2, 3...).

### Шаг 4. Ключевая особенность: Связка Альбом-Песня (M:N с `trackNumber`)
- **Добавление существующей песни в альбом:**
  - В карточке альбома нажмите «Добавить трек».
  - Выберите вкладку «Выбрать существующую песню».
  - Выберите трек, который уже есть в другом альбоме, укажите номер трека (например, `5`).
  - Сохраните — трек появится на нужной позиции.
- **Создание новой песни на лету:**
  - Нажмите «Добавить трек» -> «Создать новую песню».
  - Введите название новой песни и номер трека -> песня создастся в базе и сразу привяжется к альбому.
- **Изменение порядка треков:**
  - Измените номер трека у любой позиции (через кнопки вверх/вниз или редактирование номера).
- **Удаление трека из альбома:**
  - Нажмите иконку удаления трека из альбома. Трек пропадет из альбома, но **сама песня останется в каталоге**.

### Шаг 5. Песни (`/songs`)
- **Список песен:** виден общий список всех песен с бейджем «Входит в N альбом(ов)».
- **Детальная страница песни (`/songs/[id]`):**
  - Откройте песню, добавленную в несколько альбомов (например, сингл или хит).
  - Проверьте таблицу/список: отображаются все альбомы, где эта песня есть, и **ее индивидуальный порядковый номер в каждом из них** (главное подтверждение ТЗ!).
- **Удаление песни:** при попытке удаления песни открывается диалог с предупреждением о том, из скольких альбомов она будет исключена.

### Шаг 6. Глобальный поиск в шапке
- Введите в поисковую строку вверху страницы любой запрос (например, `the` или часть имени/названия).
- Проверьте выпадающее окно с группировкой:
  - Исполнители
  - Альбомы
  - Песни
- Клик по результату открывает соответствующую страницу сущности.

### Шаг 7. Адаптивность и мобильный интерфейс
- Откройте инструменты разработчика в браузере (F12) и включите режим эмуляции устройств (Ctrl+Shift+M):
  - **Мобильный (360×800 / 390×844):**
    - Боковая панель скрывается, появляется нижняя удобная навигационная панель (Bottom Bar).
    - Таблицы трансформируются в вертикальные карточки.
    - Тач-таргеты удобного размера (не менее 44px).
  - **Планшет (768×1024):** Сетка в 2 колонки.
  - **Десктоп (1920×1080 / 1440×900):** Боковой сайдбар, 3–4 колонки карточек.

## 3. Проверка REST API

Вы можете протестировать API напрямую через Postman, Thunder Client или `curl`:

```bash
# Получить список артистов
curl http://localhost:3000/api/artists

# Получить список альбомов с фильтром
curl "http://localhost:3000/api/albums?sort=year"

# Получить детальную информацию по альбому и его трекам
curl http://localhost:3000/api/albums/<ALBUM_ID>

# Глобальный поиск
curl "http://localhost:3000/api/search?q=rock"
```
