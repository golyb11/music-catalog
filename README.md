# Каталог музыкальных альбомов

Веб-приложение для каталогизации музыкальных альбомов. 
Этот проект реализует концепцию "одна песня может входить в разные альбомы с разными порядковыми номерами", используя связь "многие ко многим" с атрибутом.

Проект является выполнением технического задания (Specification-Driven Development).

## Технологический стек

* **Frontend и Backend:** Next.js 14+ (App Router), TypeScript
* **Стилизация:** Tailwind CSS
* **ORM и База Данных:** Prisma, PostgreSQL 16
* **Валидация:** Zod
* **Управление состоянием клиента:** React Query (TanStack Query)
* **Иконки:** lucide-react
* **Инфраструктура:** Docker, docker-compose

## Функциональность

* **Исполнители:**
  * Просмотр списка с поиском по имени и количеством альбомов.
  * Добавление, редактирование, удаление.
  * Переход к альбомам конкретного исполнителя.
* **Альбомы:**
  * Просмотр карточек с фильтром по исполнителю, году и поиском по названию.
  * Детальная страница с обложкой-плейсхолдером и списком треков.
  * Добавление треков в альбом (с указанием порядкового номера).
  * Изменение порядка треков и их удаление из альбома.
* **Песни:**
  * Просмотр списка с поиском и количеством вхождений в альбомы.
  * Детальная карточка с историей вхождений в разные альбомы.
* **Глобальный поиск:**
  * Поиск по исполнителям, альбомам и песням одновременно.

## Требования

Для запуска проекта локально вам понадобятся:
* Node.js 20+
* PostgreSQL 16 (или Docker)
* Docker (для контейнерного запуска)

## Установка и запуск локально (без Docker)

1. Клонируйте репозиторий и перейдите в папку с проектом.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте файл переменных окружения:
   ```bash
   cp .env.example .env
   ```
4. Убедитесь, что у вас запущен локальный PostgreSQL, и настройте `DATABASE_URL` в файле `.env`.
5. Примените миграции базы данных и сгенерируйте Prisma Client:
   ```bash
   npx prisma generate
   npx prisma migrate dev
   ```
6. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
7. Откройте `http://localhost:3000` в браузере.

## Установка и запуск через Docker

Запуск приложения, базы данных и применение миграций осуществляется одной командой.

1. Скопируйте файл переменных окружения:
   ```bash
   cp .env.example .env
   ```
   (Для Docker настроек по умолчанию в файле `.env` менять ничего не нужно, если порты 5432 и 3000 свободны).
2. Выполните сборку и запуск:
   ```bash
   docker compose up --build
   ```
3. После успешного старта база данных будет автоматически инициализирована. Откройте `http://localhost:3000` в браузере.

## Переменные окружения

| Переменная | Описание | Значение по умолчанию |
| --- | --- | --- |
| `DATABASE_URL` | URL подключения к PostgreSQL | `postgresql://music:music@db:5432/music?schema=public` |
| `SEED_DEMO_DATA` | Флаг для генерации демо-данных при старте | `true` |

## Структура проекта

* `app/` — роуты Next.js (страницы и API)
* `components/` — компоненты React (ui, forms, layout, tracks)
* `lib/` — утилиты, Prisma-клиент, схемы Zod для валидации
* `prisma/` — схемы базы данных Prisma, миграции и seed скрипт
* `public/` — статические файлы
* `Dockerfile` и `docker-compose.yml` — конфигурация для контейнеризации

## API (REST)

Приложение предоставляет RESTful API по пути `/api` с форматом JSON:

* `/api/artists` (GET, POST) — список и добавление исполнителей
* `/api/artists/:id` (GET, PUT, DELETE) — управление конкретным исполнителем
* `/api/albums` (GET, POST) — список и добавление альбомов
* `/api/albums/:id` (GET, PUT, DELETE) — управление альбомом
* `/api/albums/:id/tracks` (POST) — добавление песни в альбом
* `/api/albums/:id/tracks/:trackId` (PUT, DELETE) — изменение порядка или удаление трека из альбома
* `/api/songs` (GET, POST) — список и добавление песен
* `/api/songs/:id` (GET, PUT, DELETE) — управление песней
* `/api/search` (GET) — глобальный поиск
